Journey storage request console

Send requests to the local h2c storage example through this browser server. Start the Rust example first; each request below shows the storage response.

Request

An empty prefix lists every object.

Enter the logical key. The console encodes it for the URL; slashes and special characters are supported.

Optional: request one byte range, such as bytes=0-99 or bytes=-100.

The file takes precedence until you edit the text body or clear the file. Its browser-reported type fills Content-Type; you can edit it. Text defaults to text/plain. An empty body is allowed.
